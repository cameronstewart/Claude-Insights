# Procedure

## Creating a new service listing in the Service Directory

When a new service is started at IPC Health, the manager is responsible
for ensuring the service is listed in the Service Directory.

The manager is to contact the System Owner to request a new service
listing in the Service Directory. The [What role is this? What is
considered when \"approving\" as service listing? What is the criteria
to be met?]{.comment-start id="8" author="Kylie Thurlow"
date="2025-04-14T15:16:00Z"}System Owner[]{.comment-end id="8"} will
provide template to the manager for initial content input. The System
Owner approves the new service listing and provides it to the Technical
Owner, who will set up the initial service listing in Microsoft Lists.

The Technical Owner will ensure a SharePoint page is created from this
list and all automations are initiated.

## Nominating the Responsible Person and Accountable Person

The 'accountable person' for all service pages will be the
Manager/Senior Manager of that service/department. The 'accountable
person' is the default 'responsible person' however they can delegate
the 'responsible person' to someone in their team.

This is to be documented in the Service Information (Microsoft List).

## Updating the Service Directory

Regular updating of the Service Directory is essential to ensure that
the information is:

-   Accurate

-   Timely

-   Can be trusted by all users

If information is not updated in a timely manner this will reduce
confidence of all users in the Service Directory as the source of truth
for service information, which will compromise its value for all
services.

There are two key dates listed in the Service Directory to enable users
to know when information was updated.

*Date last reviewed:* The date the information was last reviewed, the
information may or may not have been updated on this date.

*Date last updated:* The date the information was last updated, i.e. the
information was changed.

This enables regular users of the Service Directory to easily identify
if there were any recent changes to information, and to also be informed
that the information has been actively reviewed (i.e. if there have been
no changes for 9 months, however the information has been reviewed in
the last 3 months).

The Service Directory information should be updated when:

-   staff start or finish in the team

-   there are new or changed programs or groups

-   there has been a change in service information (fees, eligibility
    etc)

-   someone reports that content is incorrect

The Service Directory information should be reviewed when:

**What happens if the service information is not updated in the last 3
months**

-   The Accountable Person and Responsible Person will receive a
    notification to review their pages if they have not been reviewed in
    3 months

-   The System Owner will receive a notification if the page has not
    been reviewed in 4 months. The System Owner is to follow up directly
    with the Accountable Person and relevant General Manager if
    required.

**What happens once service information is updated**

-   SharePoint page gets updated automatically

-   There is a notification on the Service Directory homepage that the
    team page has been recently updated (there will not be a
    notification if the information was only 'reviewed' not 'updated')

## How to Update service information in Microsoft Lists

1.  Select 'Lists' in the Microsoft Apps

> ![](media/image2.png){width="6.767361111111111in"
> height="3.4069444444444446in"}

2.  Select the Service Directory List (you can add this to your
    favourite lists by selecting the star in the top right corner of the
    icon)

![](media/image3.png){width="6.767361111111111in"
height="3.732638888888889in"}

3.  Find your service in the first column and click twice on the Title
    of your service

![](media/image4.png){width="6.7555555555555555in"
height="3.546527777777778in"}

4.  Select the 'Edit all' button to open the all the boxes for editing

![](media/image5.png){width="6.767361111111111in"
height="3.686111111111111in"}

5.  Edit information if required

6.  Make sure you enter today's date in the 'date last reviewed'

7.  If you edited any information, make sure you also enter today's date
    in the 'date last updated'

8.  Click 'Save' to close the box and save the updates

![](media/image6.png){width="6.767361111111111in"
height="2.2909722222222224in"}
